# MethzAI


# How to run MethzAI
## 1. Clone the repository:
   ```bash
   git clone https://github.com/sudeeraattanayake/MethzAI.git
   ```

## 2. Navigate to the project directory:
  ```bash
  cd MethzAI
  ```

## 3. Create a virtual enviroment (optional but recommend):
  ```bash
  py -3.11 -m venv methzai
  ```

## 4. Avtivate the virtual enviroment:
  ```bash
  .\methzai\Scripts\Activate.ps1
  ```

## 5. Insatll the require dependencies:
  ```bash
  python -m pip install -r requirements.txt
  ```

## 6. Run the application:
  ```bash
  python app.py
  ```
